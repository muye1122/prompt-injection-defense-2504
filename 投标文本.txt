【详细方案】
Understanding
The buyer needs four defense layers for instructions embedded in employee-entered constraints, selling points and uploaded meeting minutes: input isolation with escaped delimiters, a non-blocking injection pre-scan that records warnings and audit entries, a per-render canary leak probe, and an output post-checker for links and overreaching expressions. Flagged drafts must still reach human review and must never be sent externally; AI must not calculate monetary amounts. I will deliver runnable code, 30 fictional attack samples, an executed report, tests and documentation on the requested Node 22 / Express / React stack.

Plan
1. Build mock-server/defense.js: escape every angle bracket before wrapping user content in the input delimiter block, state in the system prompt that block content is data only, and prove that an embedded end marker cannot close the block.
2. Implement the InjectionDetector rule table for English and Chinese override phrases, role takeovers, prompt-reveal requests and base64 fragments longer than 200 characters; on a hit write a warn INJECTION_SUSPECTED issue and one security audit record without blocking generation.
3. Implement the canary probe: a random token per render, embedded in the system prompt, with an error PROMPT_LEAK issue when the token appears in the draft.
4. Implement the output post-checker for external links, expressions such as has been sent, and monetary expressions, producing a sanitized copy for review.
5. Build mock-server/index.js and server.js: in-memory audit log, review queue and report store, deterministic gateway stub, evaluation runner and REST endpoints.
6. Write 30 fictional samples in data/attack-samples.json and the React 18 / Vite 6 demo in src/, then run npm install, npm run build and npm test until all checks are green.
7. Write README.md and 验证记录.md with the real command output, the integration point and honest limitations.
